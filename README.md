# Supraland Mod для Minecraft 1.20.1 (Fabric)

## Установка

1. Скачайте Fabric Loader с https://fabricmc.net/ и установите
2. Скачайте Fabric API с https://modrinth.com/mod/fabric-api
3. Соберите мод: `gradlew build`
4. Положите JAR из `build/libs/` в `.minecraft/mods/`
5. Положите Fabric API JAR туда же

## Содержимое

- 11 сундуков с улучшениями (навсегда)
- Меч Supraland (только креатив)
- Красная пушка с шарами и лазером
- Приёмники, двери, кнопки
- Инструмент-связыватель
- Счётчик монет
- Двойной/тройной прыжок, счастье (x3 высота)

## Датапак

Папку `datapack` положите в `<мир>/datapacks/` и в игре выполните `/reload`,
затем `/function supraland:build_start`
